`seele-lock-graph [--json] [flake.lock]` shows lock node/input relationships and marks resolved follows edges. It reads the existing file without invoking Nix, updating locks, downloading inputs or reading account state. Only node/input names and topology are projected; locked/original URLs, revisions and metadata are omitted. Format 7, regular nonsymlink files ≤8 MiB, at most 1,024 nodes / 8,192 edges / 128 resolution levels are supported. Missing nodes, invalid follows paths and cycles fail before producing output. The active Jujutsu feature installs this alongside its helpers on both platforms.
