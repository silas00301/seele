Yazi `g a` runs the hovered archive through read-only `7zz t`; `seele-archive-check -- ARCHIVE` is also available on the Yazi wrapper PATH. Supported magic is ZIP, 7z, RAR, gzip, xz, bzip2 and ustar TAR. This verifies container integrity, not authenticity or malware safety. Compressed TAR checks only the outer compression stream, not an extracted tree. The helper opens one nonsymlink regular file ≤4 GiB, passes its held descriptor, never extracts, and rejects observable identity/size/time changes. Closed stdin declines password input. Limits: two threads, 512 MiB address space, 60 CPU seconds, two minutes wall time, 64 KiB output. Errors use static text instead of displaying archive member names. Originals are untouched.

Command semantics were checked against the official 7-Zip bundled manual from [7-Zip downloads](https://www.7-zip.org/download.html).
