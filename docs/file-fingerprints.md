Yazi `c h` explicitly copies the hovered regular file’s SHA-256. `seele-fingerprint -- FILE` prints it; `--copy` also transfers only the digest on clipboard stdin. Files stream in 64 KiB blocks with an 8 GiB / two-minute bound. Final descriptor and pathname identities, sizes and modification/change timestamps must match; detected changes produce no copied digest. Symlinks, directories and devices are refused. This checks an observed stable file, not an atomic snapshot against a writer that can hide metadata changes. Originals are never written. Linux uses the packaged wl-copy; macOS uses its native pbcopy.
