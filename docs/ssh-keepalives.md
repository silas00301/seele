The shared ssh-keepalive feature enables Home Manager’s SSH client configuration on Linux and macOS. Its final Host * block sends an encrypted server-alive request after 60 seconds without traffic, disconnecting after three unanswered checks. Host-specific settings and Include files appear earlier and keep OpenSSH’s first-value precedence; both fallback values are overridable Nix defaults. No SSH connection or server policy changes occur during activation. The existing Linux 1Password IdentityAgent and platform SSH_AUTH_SOCK definitions remain where they are. This does not turn on agent forwarding, multiplexing or password storage. Existing unmanaged ~/.ssh/config still needs the usual Home Manager file-conflict resolution before activation; this batch never overwrites it.

The feature uses the pinned [Home Manager SSH settings module](https://github.com/nix-community/home-manager/blob/acd21c5a3420a9d5fd0ed06299b10828267ef9ba/modules/programs/ssh.nix).
